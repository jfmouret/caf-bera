# DEFINITIONS 

**Bulletin Avalanche** : Bulletin d\'estimation du risque d\'avalanche, pour les
massifs des Alpes, des Pyrénées et de la Corse.

**METEO-FRANCE** : partie concédant un droit non-exclusif et gratuit de
réutilisation des données dans les conditions prévues par la présente
licence d'utilisation ainsi que par la licence ouverte de réutilisation
d'informations publiques version 2.0.

**Portail d'API de Météo-France**: Site internet dont l'URL est
https://portail-api.meteofrance.fr/devportal/

**API (Application Programming Interface** ou **interface de
programmation applicative)** : interface de programmation applicative
comprenant un ensemble de méthodes, fonctions et classes, mise à
disposition par l'intermédiaire d'une interface dont le but est d'offrir
des services à d\'autres logiciels et qui permet la transmission de
données dans un format structuré. Dans le cas de la présente licence
d'utilisation, le terme API désigne l'API **Bulletin Avalanche** 

**Données** : Ensemble des données météorologiques ou climatologiques
mis à disposition via l'API.

**URL** (Uniform Resource Locator) : adresse web indiquant
l\'emplacement précis d\'une ressource sur Internet.

**Point de terminaison**: Le point de terminaison est une URL
spécifique qui sert de porte d\'entrée permettant aux Réutilisateurs
d\'interagir avec l\'API, offrant ainsi accès aux fonctionnalités et aux
données fournies par celle-ci. Le point de terminaison identifiant l'API **Bulletin Avalanche** est https://public-api.meteofrance.fr/public/DPBRA/v1

**Jeton d\'accès**: Un « jeton d\'accès » est un code généré de manière
dynamique qui permet à un Réutilisateur ou à une application d\'accéder
aux ressources sécurisées de l\'API après une authentification réussie.

**Réutilisateur** : Toute personne, physique ou morale, qui utilise
l'API et les données téléchargées.

**Réutilisation** : L'utilisation des données téléchargées depuis l'API
à d'autres fins que celles pour lesquelles elles ont été produites.
Cette réutilisation est subordonnée à l'acceptation sans réserve de la
licence ouverte de réutilisation des données décrite dans la présente
licence d'utilisation, par le réutilisateur.

**Clé d\'authentification** (ou **API Key) :** Une clé
d\'authentification est une chaîne de caractères alphanumériques
statiques qui sert d\'identifiant unique, permettant d\'authentifier une
application auprès de l\'API. Elle est utilisée pour identifier
l\'application lors de l\'accès aux ressources sécurisées de l\'API,
après une authentification réussie.

**Requête** : Une requête est une demande structurée émise par un
logiciel pour interagir avec une API et obtenir des données ou exécuter
une action spécifique.

**Licence** : Contrat définissant les conditions de réutilisation des
données téléchargées depuis l'API.

# CLAUSES PARTICULIERES RELATIVES A L'API 

L'API mise à disposition par Météo-France a pour but de permettre une
récupération et une réutilisation facilitées des Données.

L'accès à l'API est ouvert à toute personne. Ce service est mis à
disposition, sous certaines conditions détaillées dans la présente
licence d'utilisation.

## A. Description de l'API

 L'API a pour but de :

-   Faciliter la mise à disposition des Données dont la responsabilité a
     été confiée à Météo-France ;

-   Permettre une Réutilisation facilitée et rapide de ces Données grâce
     à l'emploi de formats ouverts et adaptés.

En cas de difficulté concernant des données ou des méthodes de l'API
(points d'entrée), veuillez contacter le support client via le Portail
des API de Météo-France.

## B. Mise à disposition de l'API

 L'API est mise à disposition dans le catalogue d'interfaces
 applicatives du portail des API de Météo-France.

Afin de consommer l'API, il est nécessaire de :

-   S'inscrire sur le Portail des API de Météo-France et accepter les
    CPU et/ou CGV ;

-   Choisir d'utiliser l'API dans le catalogue d'API du Portail des API
    de Météo-France et accepter la présente licence d'utilisation.

 Les Réutilisateurs sont responsables des identifiants utilisés pour
 accéder à l'API et doivent respecter l'état de l'art en matière de
 sécurité informatique dans l'usage de leurs identifiants. Ils sont
 également responsables de la sécurité des équipements informatiques
 qu'ils utilisent pour accéder à l'API et aux Données, notamment en

 L'accès au portail des API de Météo-France se fait par un compte
